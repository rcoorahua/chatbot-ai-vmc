Cómo usar esta página

Simula una página de vmcsubastas.com con el widget embebido. Necesita la API local corriendo (uvicorn backend.api.main:app --reload --port 8000) con VMC_IDENTITY_SECRET en .env, y el worker de IA en otra terminal (python -m scripts.run_ai_worker) para que el bot responda. Elige un modo, aplica y usa el botón morado abajo a la derecha.

Solo para pruebas locales. Aquí el JWT de identidad se firma en el navegador con el secreto de dev para simular lo que en producción hace el servidor de VMC. El secreto real jamás va en una página web.

Consola de observabilidad · GET /dev/conversations/{id}/ai-usage

Qué decidió Subastín con cada mensaje: la capa que resolvió (trivial, guardrail, regla o modelo), qué modelo llamó, cuántos tokens gastó, cuánto costó y cuánto tardó. Lee la tabla AIUsage de la conversación de esta pestaña; nunca muestra el texto de los mensajes.

Fondo amarillo = pagó tokens · morado = guardrail (sin IA) · rojo = derivó a asesor. "Decidió" es la capa o la regla exacta (p. ej. legal_threat, guardrail:prompt_injection:…). La columna RAG muestra cada artículo del Centro de Ayuda que se recuperó para esa pregunta, con su score de similitud (por debajo de RAG_MIN_SCORE ni siquiera llega aquí): útil para ver si el bot está citando lo correcto o solo lo más parecido.
