Cómo usar esta página

Simula una página de vmcsubastas.com con el widget embebido. Necesita la API local corriendo (uvicorn backend.api.main:app --reload --port 8000) con VMC_IDENTITY_SECRET en .env, y el worker de IA en otra terminal (python -m scripts.run_ai_worker) para que el bot responda. Elige un modo, aplica y usa el botón morado abajo a la derecha.

Solo para pruebas locales. Aquí el JWT de identidad se firma en el navegador con el secreto de dev para simular lo que en producción hace el servidor de VMC. El secreto real jamás va en una página web.
