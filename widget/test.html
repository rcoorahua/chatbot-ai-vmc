Configuración

El visitante anónimo no manda identidad: sesión de pestaña (24 h) y solo FAQ — pedir asesor lo manda a crear cuenta (D-031).

Con el widget cargado: «otro usuario» firma un JWT para sub = ID + «-b»; «cerrar sesión» lo deja anónimo; «reset» olvida sesión y mensajes y vuelve a empezar con la identidad vigente.

Cómo usar esta página

Necesita la API (uvicorn backend.api.main:app --reload --port 8000) y el worker (python -m scripts.run_ai_worker) corriendo. Elige un modo, aplica, y abre el widget con el botón morado de abajo a la derecha.

⚠Solo pruebas locales. Aquí el JWT de identidad se firma en el navegador; en producción lo firma el servidor de VMC y el secreto nunca llega a una página web.

Consola de observabilidad

GET /dev/conversations/{id}/ai-usage

Un job pasa sus primeros segundos retrasado (el debounce de D-020, DelaySeconds) y el worker suele consumirlo apenas se hace visible — por eso «visibles» casi siempre marca 0. El historial de abajo se captura al encolar (la API lo registra), así no se escapa ninguno.

Cada línea es una llamada (o un atajo sin llamada) del pipeline, la más reciente arriba: Gemini al clasificar o redactar (el modelo mostrado es el que realmente respondió — si salvó el respaldo, aquí se ve), Pinecone en la búsqueda RAG, y sin API cuando una regla, trivial o guardrail resolvió gratis. Sale de las mismas filas de AIUsage que la Consola IA.

Cómo leer esta consola
Turno con llamada a IA (pagó tokens)
Guardrail: respuesta fija, sin IA
Derivó a un asesor humano
Respuesta fija (trivial / fuera de dominio)

Un turno agrupa las ejecuciones de un mismo mensaje: primero clasifica (qué intención) y luego responde. En "Decidió" ves la capa exacta que resolvió. El bloque RAG lista los artículos del Centro de Ayuda recuperados con su score de similitud — también los que quedaron bajo el umbral RAG_MIN_SCORE (atenuados y marcados «descartado»): no fueron evidencia, pero muestran cómo enrutó el retrieval. Nunca se muestra el texto de los mensajes, solo métricas.
